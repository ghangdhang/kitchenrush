# 주방 대소동 (Kitchen Rush)

마인크래프트 26.3(Paper) 서버용 협동 요리 미니게임. 하늘 위 주방에서 주문을 받아 재료를 손질하고, 굽고, 튀기고, 끓여서 접시에 담아 서빙합니다.

## 명령어 (OP)
- `/cook solo` — 1인 주방에서 영업 시작
- `/cook duo <플레이어> [플레이어...]` — 다인 주방에서 영업 시작 (최대 4명, 역할 자유, 가운데 조리대 통로로 오가기)

게임 중에는 점프할 수 없습니다.
- `/cook stop` — 영업 중단
- `/cook hud <폭>` — 왼쪽 위 HUD 위치 맞추기 (1920×1080 자동=480, 배율3=640, 배율2=960)

## 레시피
| 요리 | 재료 | 점수 |
|---|---|---|
| 샐러드 | 썬 양상추 | 20 |
| 토마토 양상추 샐러드 | 썬 양상추 + 썬 토마토 | 35 |
| 버거 | 빵 + 구운 다진 고기 | 40 |
| 스페셜 버거 | 빵 + 구운 다진 고기 + 썬 양상추 + 썬 토마토 | 70 |
| 생선튀김 정식 | 튀긴 다진 생선 + 튀긴 썬 감자 + 썬 양상추 + 썬 토마토 | 100 |

접시는 한 판에 3개뿐입니다. 서빙한 접시는 몇 초 뒤 반납대에 더러운 채로 돌아오고, 싱크대에서 설거지해야 다시 쓸 수 있습니다.

## 리소스팩
`KitchenServer/pack` 폴더가 리소스팩입니다. 서버의 ResourcepackBuilder 플러그인이 `/build`로 이 저장소의 GitHub 릴리즈에 올리고, 접속하는 플레이어에게 자동으로 보냅니다.

## 빌드
`build/build.ps1` — 텍스처·폰트를 생성해 `KitchenServer/pack`을 갱신하고, `KitchenServer/libraries`(Paper를 한 번 실행하면 생김)를 클래스패스로 플러그인을 컴파일해 `KitchenServer/plugins/KitchenRush.jar`에 넣습니다. JDK 25와 Python 3이 필요합니다.

텍스처, 주방 배치, 노트블록 음악은 모두 이 프로젝트용으로 새로 만든 것입니다.
