# 주방 대소동 (Kitchen Rush)

마인크래프트 26.3(Paper) 서버용 협동 요리 미니게임. 하늘 위 주방에서 주문을 받아 재료를 손질하고, 굽고, 튀기고, 끓여서 접시에 담아 서빙합니다.

## 명령어 (OP)
- `/cook solo` — 1인 주방에서 영업 시작
- `/cook duo <플레이어> [플레이어...]` — 다인 주방에서 영업 시작 (최대 4명, 역할 자유, 가운데 조리대 통로로 오가기)

게임 중에는 점프할 수 없습니다.

### 팀 대항전
- `/팀분배 <2|3|4>` (`/teamsplit`) — 접속자와 더미를 도팀(노랑)·개팀(연두)·걸팀(분홍)·윷팀(하늘)으로 고르게 나눔. 탭 목록·머리 위·채팅에 `[도팀]이름` 표시
- `/letscook` — 팀 수만큼 큰 팀 경기장(33×23)을 만들어 각 팀이 자기 주방에서 5분 동안 요리. 액션바에 모든 팀 점수 실시간 표시, 끝나면 순위 발표
- `/fp player <인원>` — 명령어를 친 사람의 스킨을 입은 테스트용 더미(마네킹) 소환
- `/전체초기화` (`/resetall`) — 모든 경기 종료, 팀 해제, 더미 제거

팀 경기장은 가운데 조리대 벽(가운데 3칸 통로)으로 나뉜 두 구역으로, 구역마다 재료상자·프라이팬·튀김기·서빙대·반납대·싱크대·쓰레기통이 따로 있고 도마는 안쪽 테이블에 있습니다. 접시는 6개(구역별 3개)이며, 서빙한 접시는 그 구역 반납대로 돌아옵니다. 더미 플레이어는 탭 목록에도 팀 태그와 함께 표시됩니다.
- `/cook stop` — 영업 중단
- `/cook hud <폭>` — 왼쪽 위 HUD 위치 맞추기 (1920×1080 자동=480, 배율3=640, 배율2=960)

## 레시피
| 요리 | 재료 | 점수 |
|---|---|---|
| 양상추 샐러드 | 썬 양상추 | 1 |
| 토마토 양상추 샐러드 | 썬 양상추 + 썬 토마토 | 2 |
| 버거 | 빵 + 구운 다진 고기 | 3 |
| 스페셜 버거 | 빵 + 구운 다진 고기 + 썬 양상추 + 썬 토마토 | 4 |
| 초밥 | 다진 생선 + 밥 | 3 |
| 고기 정식 | 튀긴 썬 감자 + 구운 다진 고기 + 밥 | 4 |
| 생선튀김 정식 | 튀긴 다진 생선 + 튀긴 썬 감자 + 썬 양상추 + 썬 토마토 | 5 |

밥은 쌀을 밥솥에 넣어 지어요. 프라이팬·튀김기·밥솥에서 음식이 타면 불이 나고, 끌 때까지 그 자리는 쓸 수 없어요. 구역마다 놓인 소화기를 들고 불난 곳에 우클릭을 꾹 누르면 꺼져요.

결과는 별 등급 없이 총 점수로 나옵니다. 주문을 놓쳐도 감점은 없습니다.

접시는 한 판에 3개뿐입니다. 서빙한 접시는 몇 초 뒤 반납대에 더러운 채로 돌아오고, 싱크대에서 설거지해야 다시 쓸 수 있습니다.

## 리소스팩
`KitchenServer/pack` 폴더가 리소스팩입니다. 서버의 ResourcepackBuilder 플러그인이 `/build`로 이 저장소의 GitHub 릴리즈에 올리고, 접속하는 플레이어에게 자동으로 보냅니다.

## 빌드
`build/build.ps1` — 텍스처·폰트를 생성해 `KitchenServer/pack`을 갱신하고, `KitchenServer/libraries`(Paper를 한 번 실행하면 생김)를 클래스패스로 플러그인을 컴파일해 `KitchenServer/plugins/KitchenRush.jar`에 넣습니다. JDK 25와 Python 3이 필요합니다.

텍스처, 주방 배치, 노트블록 음악은 모두 이 프로젝트용으로 새로 만든 것입니다.
